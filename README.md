
# AI-Based Landslide Susceptibility Prediction

## About the Project
This project uses Machine Learning to estimate landslide susceptibility based on geographical and environmental features.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Random Forest Classifier
- Matplotlib / Streamlit Charts

## Dataset
The project uses a geographical and environmental dataset containing 12,409 records.

## Machine Learning Algorithm
Random Forest Classifier.

## Model Performance
Initial test accuracy: 84.53%.

## Features
- Environmental input controls
- Land-cover selection
- Landslide susceptibility prediction
- Feature importance visualization
- Confusion matrix
- Classification report

## How to Run

1. Install dependencies:

   pip install -r requirements.txt

2. Train the model:

   python train_model.py

3. Start the dashboard:

   streamlit run app.py

## Important Note
This is an educational landslide susceptibility project. It does not predict the timing of landslides or provide operational emergency warnings.
